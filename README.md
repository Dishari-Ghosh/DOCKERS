# Docker Learning

My personal learning repository for Docker and containerization.

## Learning Goals

- Understand Docker fundamentals
- Learn Docker images and containers
- Practise essential Docker commands
- Understand Dockerfiles
- Learn Docker Compose
- Run and manage containers
- Practise containerizing web development and machine learning projects

## Environment

- Operating System: Windows
- Container Tool: Docker Desktop
- Terminal: PowerShell
- Code Editor: Visual Studio Code

## Practice Commands

### Verify Docker installation

```powershell
docker --version
```

### Run the test container

```powershell
docker run hello-world
```
